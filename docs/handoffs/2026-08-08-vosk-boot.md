- **Bloqueante:** `ModelLoader.ensure` lanza `zip END header not found`; la UI muestra "Fallo al arrancar" y la prueba instrumentada cae por timeout esperando "Escuchando".

## Causa raíz (verificada; no re-diagnosticar)

`context.assets.open(zip).copyTo(_bundle.zip)` escribe el ZIP **truncado al final** (pierde el EOCD).
- `ZipFile` necesita el end-of-central-directory (al final) → `zip END header not found`.
- `ZipInputStream` solo lee los local headers (inicio): "funcionaba" pero los zips Vosk usan data descriptors (tamaños en el directorio central) y deja archivos a **0 bytes** → `Model(path)` = "Failed to create a model".

Experimentos: asset Defl→copia→ZipFile ✗ · ZipInputStream ✗ (0 bytes) · asset **Stored** (`androidResources { noCompress += ".zip" }` ya en `app/build.gradle.kts`)→copia→ZipFile ✗ sigue igual. La compresión del APK no era la causa.
